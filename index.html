The game cuts the map into 9 x 9 tiles of 1.92 km. The base game lets you build on the middle 25 (9.6 km square), unlocked one at a time as the city grows; you start on the centre tile. The 81 Tiles 2 mod opens all 81 (17.28 km), and can unlock them all at once. The heightmap always covers all 81.

Put it in the game
  1. Save the PNG into the game's heightmap folder:
    • Windows: %LOCALAPPDATA%\Colossal Order\Cities_Skylines\Addons\MapEditor\Heightmaps
    • macOS: ~/Library/Application Support/Colossal Order/Cities_Skylines/Addons/MapEditor/Heightmaps
    • Linux: ~/.local/share/Colossal Order/Cities_Skylines/Addons/MapEditor/Heightmaps
  2. Start Cities: Skylines, open Tools → Map Editor, make a new map, and pick your file under Import heightmap.
  3. Sea level. Coastal maps: set it to the value under “Sea level in game” above. Inland maps: drag it below the lowest riverbed (under “In game” above) so the valleys stay dry.
  4. Water sources. Under Water, place one source on each dark blue pin, where a river enters the map, and raise it until the bed fills to its banks. Grey pins mark where a river leaves: put nothing there, it drains off the map's edge. Put one in the middle of each lake (light blue pins) and drag its height to the lake's surface. Then unpause and watch: if a valley floods, lower the source.
  5. Starting tile. It must have water and a highway in and out (Map Settings → Start Area moves it). Draw highways from the map edge along the real ones.
  6. Playing with 81 Tiles 2? Disable it before opening the Map Editor; the mod turns the editor off because it breaks saved maps.

The file is 1081 x 1081 px, 16-bit greyscale, 17.28 km across, with black = 0 m and white = 1024 m. The lowest ground sits at 50 m so water has room below the land; when the relief is too tall for 1024 m, heights are squeezed to fit (shown under “Height”).
