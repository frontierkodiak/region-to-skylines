03 / Proposed bar

A forest is not a specimen tree.

Forest fill

Provisional main-mesh target, rounded from the built-in 75th percentile. Budget at 100k–250k map instances, then measure what is actually visible at near and far zoom.

Shared texture palette

1,024 px target

Count texture memory once per unique texture, including mipmaps and formats. Start with a 128 MiB palette target; audit sharing and alpha overdraw. These memory targets are proposals, not native measurements.

Native A/B/A

≤10% p95 regression

Five repeated A/B/A trials at two zooms with the same positions and stock population. Baseline drift above 5% makes the comparison inconclusive. Wall-frame timing is not isolated GPU time.

Above-target assets can still earn an accent (≤5k instances) or specimen (≤200) role after separate review. A forest-fill failure is not a claim that the artwork is bad.

Full review requirements
  • Correct size class: height and crown spread, native random scale, pivot/root placement and ≤20% scale error against a sourced real plant reference.
  • Readable canopy and trunk at gameplay distance; coherent colour under stock lighting; no severe repetitive silhouette or root float.
  • Native billboard silhouette, colour, transition and multiple viewing directions; avoid white/black alpha fringes, excessive empty cards and heavy overdraw.
  • Wind should move foliage plausibly without a bending trunk; distinguish actual snow response from a separate winter asset. Static fall colour is not seasonal simulation.
  • No embedded assemblies or required mods for the default Workshop vegetation profile. Resolve every hard dependency; optional visual suggestions are separate.
  • Fresh-city load, save/reload and version compatibility. An old update date alone does not mean a static asset is broken.
  • Public original author page, credit and intact recommendation link. Reference assets; never bundle or redistribute their CRPs or textures. Verify any special terms or provenance concerns.
  • Also review palette cohesion, size/age variants, silhouette diversity, deterministic prefab names, missing assets and dependency expansion.

05 / Provenance

What this ledger can establish

Primary sources: Valve’s public metadata API, MrMaison’s Nature Collection, pdelmo’s low-poly collection, creator tree guide, and RESOLVE Ecoregions 2017 biome scheme. Mesh and texture facts come from blade’s files, not scraped marketing counts.

All installed serialized .assets files were scanned for TreeInfo; natural PropInfo inclusion is name-screened, not proven exhaustive. Installed files do not prove DLC ownership or runtime availability. Workshop discovery covers the Tree tag and named prop/decal searches, not every natural asset ever uploaded. Dependencies are public-page declarations, not proof that an undeclared mod is unnecessary. Package metrics exist only for cached packages.
