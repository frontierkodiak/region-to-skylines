# Vegetation demand: current SDM evidence

Verified 2026-11-23. Scope: bounded primary-source review, not an exhaustive leaderboard. User constraints: **“Start from the best methods available now, not from what we have”** and **“Inside cities this should follow what’s actually planted, such as street trees and parks, not only the natural vegetation.”**

## Recommendation

Use two distinct targets: **urban planted genus composition/counts**, anchored in municipal inventories and park surveys; and **non-urban occurrence/habitat composition**, supported by SDMs and vegetation plots. Do not normalize presence-only occurrence scores into claimed tree abundance. Inventory coverage must be explicit: a street-tree inventory is not a census of all park/private trees.

For the next bounded model comparison, use **an inventory-conditioned RF/boosted-tree composition baseline**, **a modern satellite/environment model with MIAM-style missing-modality training**, and **GeoTreeCLIP as a forest/tree-image challenger**. Retain SINR as a geographic prior/control, not the preferred method merely because it is already held. Select the winner on held-out city/park blocks and cities, not the published cross-task metrics. This is my recommendation, not a claim those papers already solve urban abundance.

## The newest global plant benchmark changes the comparison

**SAGE (September 2026)** joins 89.8M GBIF occurrences with 53,336 sPlotOpen plots for 5,771 identified plants at 1 km. RF and the optimized DeepSDM are essentially tied overall (reported AUROC 85.9% vs 85.8%); gains depend on species sampling/prevalence, spatial aggregation, thinning, target-group background and species weighting. These are not abundance metrics.

Crucially, it **filters to native ranges** and explicitly **does not remove GBIF training occurrences inside evaluation cells**. Independent observation sources are therefore **not spatial holdout**. This makes it useful methodology/evaluation evidence, but not a ready urban planting layer; applying its native mask would erase introduced ornamentals. Code MIT; released models/configs/predictions exist. [arXiv:2609.31082](https://arxiv.org/abs/2609.31082), pp. 5–6, 11, 17; Zotero **QHN9P3CN**; [repository](https://github.com/earens/sage-sdm-benchmark), [model archive](https://doi.org/10.5281/zenodo.21335338).

Source SHA256 `a05e2ff2ecca6471c11fc48a06f0c6e28aa812d4ac87f303a1d9af860dd353af`. `Species` is original identity; `scientificFinal` is a WFO/WCVP resolution, not fresh GBIF reconciliation. Exact unmatched names mean unknown coverage. Paper record **BDJPBIW6** holds the **2023 bioRxiv preprint**, not final journal PDF: [DOI](https://doi.org/10.1111/gcb.16914); preprint pp. 4–6 read. These ranges/identities do not establish urban counts or an absolute tree/shrub boundary.

Broader alternative: `sdm-artifacts/tree-taxa.json` contains **87,845 unique species names/GBIF species keys**, **3,774 genera**, 301 families from the GlobalGeoTree initial catalog. It is **not** the forest-filtered 21,001-species training set, despite Appendix A1 wording. Pinned HF revision `dc0eb3d18623e80c5e53f740356479e46be9d450`; source hash and current license snapshot recorded. Old indexed README had NC wording; fresh pinned README now explicitly CC-BY-4.0. Prefer exact species/key filtering to genus membership: a tree-capable genus can also contain shrubs/herbs.

## Executable next trial

No model inference or training was run in this research turn; artifact/schema/license checks and whitelist generation were run.

1. Freeze inventory labels, dates and coverage; aggregate **count/share by genus** separately for street, park and other covered strata. Hold out complete spatial blocks/parks, then entire cities. Deduplicate colocated GBIF/inventory evidence across splits. Preserve introduced/cultivated records for the urban target and explicitly model observation effort.
2. Predict inventory counts/shares using location, imagery, canopy/height, land use, management context and climate. Compare a strong tabular learner with a MIAM-style multimodal model and forest GeoTreeCLIP features. Score genus-share error, rank overlap, calibration/interval coverage and performance by city/coverage, not only occurrence AUROC. Missing inventory should produce uncertainty, not invented precision.
3. Current MIAM reproduction route: download `geoplant_miam.pt` from `zbirobin/MIAM`, place at `models/miam/miam.pt`, install repository requirements, set GeoPlant data path, then run `python maskSDM/evaluation/experiments/all_together.py`; its README documents W&B config fallback. This verifies the published-domain pipeline, **not** urban transfer. [exact instructions](https://github.com/zbirobin/MIAM/blob/main/maskSDM/README.md).
4. SAGE RF/DeepSDM is an independently useful global non-urban control. Data DOI `10.5281/zenodo.21297133`; optimized training entry point `python src/main.py --exp optimized_deepsdm fit`. Keep published native-range evaluation separate from a city-planted evaluation. SINR's lightest documented smoke path is its pretrained bundle plus `python viz_map.py --taxa_id <inat_id>`.
