## What is established

The query tests exact native `[segment, lane, offset]` endpoints through
`PathManager.CreatePath`, using Train type, All categories, the retained lane
mask, seed 857 and a 100000 maximum path length. Native success must be complete
and released, with returned first/last positions equal to the requested
literal Outside offsets. Segment membership or a midpoint success is not
enough.

Direction selection uses the native Forward/Backward bits, with segment Invert
accounted for. AvoidForward=11 and AvoidBackward=7 contain both bits; their
display names are not one-way restrictions. The first new selector's name
comparison was a separate recorded mistake, not a retrospective explanation
of the historical Rio48/HongKong16 failures.

These observations support a deterministic **candidate rule**: distinct native
Outside nodes and segments, compatible Train/lane types, and valid entry/exit
direction bits. A positive observation additionally requires an actual exact
native path in a package-bound opening context. Metadata counts and undirected
segment components do not supply that evidence.

Native lane-to-lane connectivity, junction rules, path costs and failures are
still unfitted as a general place/export predicate. Even stock Hanami has
selected failures. Neither finite exhaustive candidates nor the fixed request
cap defines a global native-negative oracle. The maximum path length and this
opening protocol also bound the claim.

## Identity and preservation

Every final-protocol opening binds the actual executable, full resolved loaded
assembly-file inventory, plugin flags, native entry/traffic state, mod and
launch/opening PID/start to the same observation and package. Dynamic
assemblies remain explicitly excluded; unresolved file identities fail closed.
Reported native/panel errors and builtin/bridge/harness flags remain in the raw
bytes. This is **FILE identity**, not memory attestation or strict no-mods.

The native source and mod do not change during this continuation. The new
driver only chooses fresh output names, skips completed cases and joins its
owned telemetry. Its source, sampler, exact package/settings, stock references
and case mapping are frozen before the new queries. Reused calibration
references are not new observations or votes.

The initial final-protocol manifest has 33 raw files. This continuation adds
50, for 83 raw files under the final protocol. The two earlier diagnostic
revisions retain another 28 separately. Both initial and continuation bytes
are hash-verified; no old file or derived field was rewritten to manufacture
preservation. The original outside-v1 study still reproduces 1269 rows,
143 raw files and 17 attempts.
