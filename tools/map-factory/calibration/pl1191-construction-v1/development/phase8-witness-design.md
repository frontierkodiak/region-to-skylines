## Read-only stream-refusal witnesses

Two shapes considered: change the frozen planner to emit more fields, or add
a read-only diagnostic over its complete physical protocols. Use the latter:
the old compiler, masks, inventories, refusals and protocol bytes stay intact.
The new witness protocol owns copied inputs and binds its own source closure.
No physical package or native observation is produced.

For every numerically feasible graph, attribute every guarded channel/bank
node to every contacting foreign stream clip or infrastructure source. Replay
the union counts against the frozen guards. Stream admission distances use
the original nearest-node128m rule. Infrastructure uses original raster128m,
corridor112m and existing analytic landing/control radii. Raw clipped-polyline
distance is supplemental evidence, never a replacement mask. Keep full source
row/clip/hash identity, explicit scope, same-source fragments and exact shared
captured/native vertices separate from proximity or proven hydraulic identity.
No name-based merging, inferred junction acceptance or radius changes.

For every DAG bound refusal, replay greatest stages and retain a directed path
to one limiting ancestor upper bound and its minimum untouched bank nodes.
Record source-part ownership along the path, local versus propagation-only
conflicts, depth/cut deficit and optional captured-input/bank comparisons.
Comparison requires exact matching geometry and authored terrain hashes; it
does not import any older native-floor qualification. Flow direction and the
nearest16m graph/bank model remain provisional.

Tests will check path certificates against the original solver, source-piece
contact attribution at the unchanged buffer boundary, explicit underground
and same-row clipping relations, infrastructure raster/analytic attribution,
complete guard unions and tamper/coherent-omission rejection. Run all three
frozen development protocols; retain both base refusals. Only after witnesses
exist decide what junction/outlet/supply refinement the evidence supports.
The holdout stays unopened and every water promise stays unknown.
